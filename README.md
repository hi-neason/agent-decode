# agent-decode

通过场景与源码，逐步理解 Agent 技术栈。

从一次 LLM 调用出发，让一个小型教学 Agent 逐步学会使用工具、持续完成任务、管理上下文，并在明确的权限与验证机制下运行。每一步都由当前场景的问题引出新的技术方案，再连接到下一个问题。
